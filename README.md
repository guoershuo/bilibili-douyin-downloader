# autoDownloads · 本地视频下载台

把 B 站和抖音的下载脚本，收进一个浏览器页面。没有 Tkinter 窗口，没有命令行粘贴，也没有云端上传：打开页面、贴链接、选清晰度，文件写入本机目录。

## 打开

1. 双击 `start.bat`，浏览器会自动打开 `http://127.0.0.1:8765/`。首次启动会自动创建 `.venv` 并安装依赖（约 1-2 分钟），无需先手动跑 `setup.bat`。
2. 把链接粘贴到页面，选择清晰度和保存目录，点击「开始下载」。

左侧栏底部的「退出服务」会停止本地服务。直接关掉浏览器标签页不会停止服务。

## 功能

- **B 站 / 抖音双平台**：一个页面切换，批量粘贴链接，支持分享文案。
- **B 站**：粘贴链接后自动读取该视频**真实可用**的清晰度（含 1080P60 这类高帧率档），页面直接按视频给的档位渲染；换清晰度会**另存一份带清晰度后缀的文件**，不覆盖已有视频（勾选「覆盖下载」才覆盖）。支持 UP 主空间 / 数字 mid、全部视频、数量限制、按作者分文件夹。
- **抖音**：同样优先使用视频返回的档位，读不到时回退默认档位；主页全部作品、自动 / 浏览器 / yt-dlp 引擎、优先 H.264、保存封面与 `.info.json`。
- **实时任务面板**：百分比、条目进度、开始时间、保存目录、逐行日志、停止、打开目录；任务结束会核对是否真的生成了文件。
- **本机环境检查**：ffmpeg、B 站 Cookie、抖音浏览器配置、磁盘空间。
- **登录入口**：
  - B 站点「登录 B 站」会打开一次浏览器，导出 `cookies.txt`；
  - 抖音点「登录抖音」会打开一次浏览器，登录态保存在 `.browser-profile`。
- **状态留在本机**：前端设置存在浏览器 `localStorage`；下载文件、Cookie、日志都在项目目录或你选择的目录里。
- **无 CDN**：页面只用本机静态资源，断网也能打开界面（下载本身当然需要网络）。

## 环境要求

- Windows 10/11，Python 3.10+。
- **B 站下载需要 ffmpeg**。页面「本机环境」里 ffmpeg 缺失时点「一键下载 ffmpeg」，会自动把官方 Windows 构建解压到 `tools\ffmpeg.exe`；直接点「开始下载」也会先自动安装。也可以自己把 `ffmpeg.exe` 放进 `tools\`，或用 winget：`winget install Gyan.FFmpeg`。
- 抖音的浏览器解析需要本机 Edge / Chrome / Chromium。登录一次后会导出 `cookies.txt` 到浏览器配置目录，下次启动自动灌回，不需要重复扫码。

## 项目结构

```
start.bat                 启动本地页面（自动创建 .venv、装依赖、重启旧实例）
setup.bat                 手动重建环境（start.bat 会自动调用）
web_app.py                本地 HTTP 服务、任务队列、登录与 API
ffmpeg_install.py         ffmpeg 自动下载与解压
web/index.html            页面结构
web/assets/styles.css     视觉系统与响应式布局
web/assets/app.js         表单、任务轮询、日志、平台切换、清晰度探测
bilibili_downloader.py    B 站下载核心（CLI）
douyin_downloader.py      抖音下载核心（CLI）
browser_engine.py         抖音浏览器解析 / 登录态
tests/                    单元测试（unittest）
requirements.txt          yt-dlp、websocket-client
web.log                   运行日志（自动生成）
```

命令行仍然可用：`bilibili.bat`、`douyin.bat`。网页只是把同样的下载核心包装成了本地 Web UI。

## 常见问题

**页面显示「本地服务未连接」**  
请通过 `start.bat` 打开，不要直接双击 `web/index.html`。启动失败时查看项目根目录的 `web.log`。

**端口被占用**  
服务会从 `8765` 开始自动尝试后面的端口，浏览器会打开实际端口。重复运行 `start.bat` 时只会复用「本目录启动、且页面能正常打开」的实例；代码过期会先自动停掉它再启动新的。若端口上是别的目录里的同名实例，或者那个实例已经打不开页面（例如项目被搬走后旧进程还在跑），启动时会提示一句并改用新端口，不会再去打开那个打不开的页面。

**「打开目录」没有弹出资源管理器**  
个别机器/安全策略不允许应用进程调起系统 shell（`os.startfile` 报 `WinError 5`）。这种情况下页面会弹出一个「下载目录」窗口，直接列出文件名、大小和修改时间，并可一键复制路径，粘到资源管理器地址栏即可。

**B 站下载提示没有找到 ffmpeg**  
按上面的方式安装 ffmpeg，再点页面「本机环境」里的「重新检查」。B 站使用 DASH 音视频分离流，必须合并。

**B 站高画质失败 / 登录过期**  
点「登录 B 站」重新登录。登录状态保存在 `cookies.txt`，页面不会上传它。

**抖音首次解析要求登录**  
点「登录抖音」会打开一次可见浏览器；登录完成后关闭浏览器，回到页面重新开始任务。登录态保存在 `.browser-profile`。
